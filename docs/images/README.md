# Image attribution

`masker-python.png` and any locally generated `masker-matlab.png` contain an
adapted display of the Case 10 MRI and supplied prostate label from:

> Fedorov, Andrey; Nguyen, Paul L.; Tuncali, Kemal; Tempany, Clare (2015),
> *Annotated MRI and ultrasound volume images of the prostate*, Zenodo,
> <https://doi.org/10.5281/zenodo.16396>.

The source dataset is licensed under
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Changes:
the NRRD arrays were converted to NumPy/raw formats, normalised and displayed by
Masker, and the supplied label was rendered as a coloured overlay. These images
are available under the same CC BY-NC-SA 4.0 license and are not covered by the
repository's Apache-2.0 license.

The dataset authors request citation of:

> Fedorov et al., “Open-source image registration for MRI–TRUS fusion-guided
> prostate interventions,” *International Journal of Computer Assisted
> Radiology and Surgery* 10, 925–934 (2015),
> <https://doi.org/10.1007/s11548-015-1180-7>.
